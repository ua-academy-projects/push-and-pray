# Локальний центр сертифікації

Після provisioning UI VM Caddy створює локальний центр сертифікації у
Docker volume `wildlife_caddy_data`. Приватний ключ CA залишається лише в
цьому volume і не експортується.

Публічний кореневий сертифікат автоматично з'явиться тут:

```text
tls/wildlife-local-root-ca.crt
```

На кожній Linux-машині, з якої відкривається UI, встановіть його в системне
сховище довіри командою з кореня проєкту:

```bash
bash ./install-local-ca.sh
```

Скрипт підтримує Debian/Ubuntu та RHEL/Fedora-сумісні системи й за потреби
викликає `sudo`.

Після перезапуску браузера відкрийте:

```text
https://192.168.10.213
```

Не копіюйте приватний ключ із Docker volume. Після `vagrant destroy ui`
volume і CA буде видалено; новий CA доведеться встановити як довірений знову.
